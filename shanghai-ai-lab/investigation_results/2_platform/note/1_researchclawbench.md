# ResearchClawBench (arXiv:2606.07591)

## 概要
- 40の科学発見タスク、10の科学ドメイン（天文学、化学、地球科学など）
- ResearchHarnessによる軽量評価（Web検索/ファイル/実行ツール）
- RADSスコア評価（50点=目標論文レベル再発見）

## 実験環境
- NVIDIA A100 GPU使用
- SGLang推論エンジン採用

## 評価方法
- 専門家作成の多モーダル評価基準
- 目標論文を非公開、再発見を評価
- 平均スコア：Claude Code 21.5、Claude-Opus-4.7 20.7
