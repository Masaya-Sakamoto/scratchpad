# プラットフォーム基盤調査レポート

## 1. 調査対象の概要

本レポートは、上海AI実験室のオンプレミスKubernetes環境へのデプロイに必要なベースラインと期待動作を定義するため、以下の6資料を調査対象として作成した。

### 1.1 対象資料一覧
1. **ResearchClawBench** (arXiv:2606.07591) - 科学発見ベンチマーク
2. **SciDisco** (arXiv:2607.28990) - 科学推論フレームワーク
3. **Acme Datacenter** (arXiv:2403.07648) - データセンター設計
4. **InternLM/lmdeploy API Server Documentation** - 推論エンジン設定
5. **Kubernetesクラスタ設計** - 基盤インフラ設計
6. **SCP自己ホスト** - データ基盤設計

## 2. 上海AI実験室の実際のインフラ構成

### 2.1 ハードウェア構成

#### GPU/計算リソース
- **Acme Datacenter**: 4,704 A100 GPU（Seren: 286ノード×8GPU, Kalos: 302ノード×5GPU）
- **ResearchClawBench実験**: NVIDIA A100 GPU使用
- **SCP自己ホスト推奨**: A100 × 4（Data Server）

#### CPU/メモリ
- **Acme Datacenter**: 
  - Seren: 128CPU/ノード、1TBメモリ/ノード
  - Kalos: 2,048CPU/ノード、1TBメモリ/ノード
- **Kubernetes推奨**: 
  - GPUノード: 32-64C/256-512GB
  - ワーカー: 32-128C/128-512GB

#### ネットワーク
- **Acme Datacenter**: 
  - Seren: 200Gb/s
  - Kalos: 1,000Gb/s
- **Kubernetes推奨**: 10GbE〜200Gb/s（InfiniBand）

#### ストレージ
- **Kubernetes推奨**:
  - Longhorn: 3レプリカ分散配置
  - MinIO: 4ノード以上、100TB+
  - CephFS/NFS: 3ノード以上

### 2.2 ソフトウェア構成

#### Kubernetes設定
- **推奨バージョン**: 1.25+
- **CNI**: Calico（高性能）またはCilium（eBPFベース）
- **CSI**: Longhorn（ブロック）、MinIO（オブジェクト）、CephFS（ファイル）
- **サービスメッシュ**: Istio（完全閉域、mTLS有効化）

#### 推論エンジン
- **SGLang**: `tp-size 1`, `mem-fraction 0.8`, `context-length 262144`
- **vLLM**: `tensor-parallel-size 1`, `max-model-len 262144`
- **エンドポイント**: `http://localhost:8000/v1`

#### 学習フレームワーク
- **Slime Framework**: SciDiscoで使用
- **ResearchHarness**: ResearchClawBenchで使用（軽量、Web検索/ファイル/実行ツール）

### 2.3 データ基盤

#### SCP自己ホスト（Hub-Spokeモデル）
- **SCP Hub**: 計画・スケジューリング・権限管理
- **SCP Server**: ローカルモデル・DB・計算機・実験装置管理
- **科学ツール**: 2,200+
- **Scientific Skill**: 200+

## 4. ベースラインとしての要件定義

### 4.1 最小構成（Pilot）
- **制御平面**: 3ノード（16C/64GB/SSD 500GB/10GbE）
- **ワーカー**: 4ノード（32C/128GB/SSD 1TB/10GbE）
- **GPUノード**: 2ノード（32C/256GB/NVMe 2TB/A100×4）
- **ストレージ**: 10TB（MinIO）
- **ネットワーク**: 10GbE

### 4.2 中規模構成（研究部門）
- **制御平面**: 5ノード（24C/128GB）
- **ワーカー**: 8-12ノード（64C/256GB）
- **GPUノード**: 4-8ノード（64C/512GB/A100×8）
- **ストレージ**: 100TB（MinIO）
- **ネットワーク**: 25/100GbE

### 4.3 大規模構成（PB級）
- **制御平面**: 7-9ノード（64C/256GB）
- **ワーカー**: 20-50ノード（128C/512GB）
- **GPUノード**: 16-32ノード（128C/1TB/A100/H100×8）
- **ストレージ**: PB級（分散ストレージ）
- **ネットワーク**: InfiniBand 200Gb/s

## 5. 期待される動作

### 5.1 推論性能
- **SGLang/vLLM**: 256Kコンテキスト、バッチ処理
- **エンドポイント**: OpenAI互換API（/v1/chat/completions）

### 5.2 学習性能
- **Slime Framework**: DAGベースの検証、ターンレベル報酬
- **ResearchHarness**: 軽量評価、Web検索/ファイル/実行

### 5.3 運用特性
- **高可用性**: 3レプリカ、マルチゾーン
- **スケーラビリティ**: クラスタオートスケーラ、GPU Operator
- **セキュリティ**: 完全閉域、mTLS、RBAC

## 6. 結論と推奨構成

### 6.1 ピボット環境の推奨構成
