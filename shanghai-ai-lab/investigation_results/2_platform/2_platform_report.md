# 上海AI実験室 オンプレミスKubernetes環境 基礎調査レポート

## 1. 調査対象の概要

本レポートは、上海AI実験室のオンプレミスKubernetes環境へのデプロイに必要なベースラインと期待動作を定義するため、以下の6資料を精査し、公開情報から抽出したデータを統合して作成したものです。

### 1.1 対象資料一覧と概要

#### 1.1.1 ResearchClawBench (arXiv:2606.07591)
**概要**: 科学発見タスクのためのベンチマーク
- **タスク数**: 40タスク、10科学ドメイン（天文学、化学、地球科学など）
- **評価ハンス**: ResearchHarness（軽量、Web検索/ファイル/実行ツール）
- **評価方法**: RADSスコア（50点=目標論文レベル再発見）
- **実験環境**: NVIDIA A100 GPU、SGLang推論エンジン

#### 1.1.2 SciDisco (arXiv:2607.28990)
**概要**: 科学推論のためのフレームワーク
- **システム**: SciThèque（データ→仮説→検証のサンドボックス）
- **検証**: DAGベースの検証システム（隠された証拠グラフ）
- **報酬**: DiscoPO（ターンレベルの報酬でトレーニング）
- **フレームワーク**: Slime Framework、SGLang推論エンジン
- **学習パラメータ**: バッチサイズ16、グループサイズ8
- **実験環境**: NVIDIA A100 GPU

#### 1.1.3 Acme Datacenter (arXiv:2403.07648)
**概要**: 上海AI実験室のデータセンター設計
- **クラスタ構成**:
  - Seren: 286ノード、8GPU/ノード、128CPU/ノード、1TBメモリ/ノード、200Gb/sネットワーク
  - Kalos: 302ノード、5GPU/ノード、2,048CPU/ノード、1TBメモリ/ノード、1,000Gb/sネットワーク
- **総GPU数**: 4,704 A100
- **ワークロード特性**:
  - ジョブ持続時間：従来DLワークロードの2.7-12.8倍短い
  - 評価ジョブ：92.9%だがGPU使用量0.8%
  - 前学習ジョブ：3.2%だがGPU使用量94.0%
  - GPUメモリ使用量：75%（60GB）
  - GPU利用率：99%
- **システム最適化**: 耐障害性前学習、評価のための分離スケジューリング

#### 1.1.4 InternLM/lmdeploy API Server Documentation
**概要**: 推論エンジン設定ドキュメント
- **推論エンジン**: SGLang/vLLM
- **設定パラメータ**:
  - SGLang: `tp-size 1`, `mem-fraction 0.8`, `context-length 262144`
  - vLLM: `tensor-parallel-size 1`, `max-model-len 262144`
- **エンドポイント**: `http://localhost:8000/v1`
- **API**: OpenAI互換（/v1/chat/completions, /v1/models, /v1/completions）

#### 1.1.5 Kubernetesクラスタ設計 (1_kubernetes_design.md)
**概要**: 基盤インフラ設計
- **ノード構成**: 制御平面/ワーカー/GPUノード
- **ストレージクラス**: Longhorn（ブロック）, MinIO（オブジェクト）, CephFS/NFS（ファイル）
- **ネットワーク**: Calico/Cilium（CNI）, Istio（サービスメッシュ）
- **推奨構成**: 最小構成/中規模構成/大規模構成

#### 1.1.6 SCP自己ホスト (3_scp_self_hosted.md)
**概要**: データ基盤設計
- **アーキテクチャ**: Hub-Spokeモデル（1 Hub + 複数Server）
- **ハードウェア要件**: Hub/Data Server/Instrument Server
- **ツール統合**: 2,200+科学ツール、200+ Scientific Skill
- **権限管理**: IAM設計（ユーザー/ロール/グループ）

## 2. 上海AI実験室の実際のインフラ構成

### 2.1 ハードウェア構成

#### 2.1.1 GPU/計算リソース
**Acme Datacenter（実環境）**:
- **総GPU数**: 4,704 A100
- **Serenクラスタ**: 286ノード × 8GPU = 2,288 GPU
- **Kalosクラスタ**: 302ノード × 5GPU = 1,510 GPU
- **GPUタイプ**: NVIDIA A100（80GB VRAM）

**研究実験環境**:
- **ResearchClawBench**: A100 GPU使用
- **SciDisco**: A100 GPU使用
- **SCP自己ホスト推奨**: A100 × 4（Data Server）

#### 2.1.2 CPU/メモリ構成
**Acme Datacenter**:
- **Seren**: 128CPU/ノード、1TBメモリ/ノード
- **Kalos**: 2,048CPU/ノード、1TBメモリ/ノード

**Kubernetes推奨構成**:
- **GPUノード**: 32-64C/256-512GB
- **ワーカーノード**: 32-128C/128-512GB
- **制御平面**: 16-64C/64-256GB

#### 2.1.3 ネットワーク構成
**Acme Datacenter**:
- **Seren**: 200Gb/s
- **Kalos**: 1,000Gb/s

**Kubernetes推奨**:
- **最小構成**: 10GbE
- **中規模構成**: 25/100GbE
- **大規模構成**: InfiniBand 200Gb/s

#### 2.1.4 ストレージ構成
**Kubernetes推奨**:
- **Longhorn**: 3レプリカ分散配置（ブロックストレージ）
- **MinIO**: 4ノード以上、100TB+（オブジェクトストレージ）
- **CephFS/NFS**: 3ノード以上（共有ファイルストレージ）

### 2.2 ソフトウェア構成

#### 2.2.1 Kubernetes設定
- **推奨バージョン**: 1.25+
- **CNI**: Calico（高性能）またはCilium（eBPFベース）
- **CSI**: 
  - Longhorn（ブロック）
  - MinIO（オブジェクト）
  - CephFS/NFS（ファイル）
- **サービスメッシュ**: Istio（完全閉域、mTLS有効化）
- **Ingressコントローラ**: NGINXまたはTraefik

#### 2.2.2 推論エンジン設定
- **SGLang**: 
  - `tp-size 1`（テンソル並列化）
  - `mem-fraction 0.8`（GPUメモリの80%）
  - `context-length 262144`（256Kコンテキスト）
- **vLLM**: 
  - `tensor-parallel-size 1`
  - `max-model-len 262144`
- **推論エンドポイント**: `http://localhost:8000/v1`
- **API互換**: OpenAI互換

#### 2.2.3 学習フレームワーク
- **Slime Framework**: SciDiscoで使用
- **ResearchHarness**: ResearchClawBenchで使用（軽量、Web検索/ファイル/実行ツール）

### 2.3 データ基盤

#### 2.3.1 SCP自己ホスト（Hub-Spokeモデル）
- **SCP Hub**: 計画・スケジューリング・権限管理
- **SCP Server**: ローカルモデル・DB・計算機・実験装置管理
- **科学ツール**: 2,200+（データ取得、分析ツール、専門ツール、可視化）
- **Scientific Skill**: 200+（生命科学、材料科学、地球科学、化学）

#### 2.3.2 権限管理
- **ユーザー**: 研究者、管理者、ゲスト
- **ロール**: 
  - Admin: 全権限
  - Researcher: 実験実行権限
  - Viewer: 閲覧のみ
- **グループ**: プロジェクトベース

#### 2.3.3 監査・トレーサビリティ
- **監査ログ**: 全API呼び出し、JSON形式、90日以上保持
- **トレーサビリティ**: 実験ID、プロベナンス、再現性記録
