# SCP Technical Report (arXiv:2512.24189)

## 出典元
- 論文: arXiv:2512.24189 "SCP: Accelerating Discovery with a Global Web of Autonomous Scientific Agents"
- リポジトリ: GitHub - InternScience/scp

## 概要
SCP (Science Context Protocol) は、自律的な科学エージェントのためのグローバルなコラボレーションネットワークを構築し、科学発見を加速させるためのオープンソース標準プロトコル。

## 2つの基盤的支柱

### 1. 統一リソース統合 (Unified Resource Integration)
- 科学的リソース（ソフトウェアツール、AIモデル、データセット、物理機器）を記述・呼び出すためのユニバーサル仕様
- プロトコルレベルでの標準化により、AIエージェントやアプリケーションが異なるプラットフォームや組織境界を越えてシームレスに能力を発見・呼び出し・組み合わせ可能

### 2. 調整された実験ライフサイクル管理 (Orchestrated Experiment Lifecycle Management)
- セキュアなサービスアーキテクチャ
- 集中型SCP Hubと連合型SCP Servers
- 完全な実験ライフサイクル管理（登録、計画、実行、監視、アーカイブ）
- 細粒度の認証・権限管理
- 追跡可能なエンドツーエンドワークフローの調整（計算ラボと物理ラボの橋渡し）

## SCPアーキテクチャ
- **SCP Hub**: 集中管理、計画、スケジューリング、権限管理
- **SCP Servers**: 連合型サーバー、ローカルモデル、DB、計算機、実験装置管理

## 統合リソース
- **科学ツール**: 2,200+
- **Scientific Skill**: 200+

## 特徴（MCPとの比較）
| 機能 | MCP | SCP |
|------|-----|-----|
| プロトコル標準化 | 一般的なツール呼び出し | 構造化された完全な科学実験ワークフロー |
| 大量実験サポート | 組み込み実験管理なし | バッチ実験とコンテキスト管理サポート |
| マルチエージェントコラボレーション | ポイントtoポイント通信 | 集中型オーケストレーションとタスク配分 |
| 実験室機器統合 | カスタムアダプタ必要 | 標準化されたデバイスドライバとインターフェース |

## 主要コンポーネント
- **計画マネージャ**: 実験計画の作成と管理
- **スケジューラ**: リソース割り当てとタスクスケジューリング
- **権限管理（IAM）**: 細粒度のアクセス制御
- **監査ログ**: 全操作の追跡と記録
- **可視化ダッシュボード**: 実験進捗の監視

## 実験室統合
- 乾燥実験（Dry Lab）ツール: 分子モデリング、計算化学、データ解析
- 湿式実験（Wet Lab）統合: 実験装置の自動化制御
- 安全インターロック: 実験の安全性確保

## 追跡可能性
- 実験ID: 一意の識別子
- プロベナンス: データと計算の起源追跡
- 再現性: 環境とパラメータの記録
